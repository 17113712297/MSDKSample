ANDROID RTMP -> SRS -> WHEP

本机低延迟直播预览页

这页默认连接本机 SRS 的 obs1 流，适合在 Windows 上把 SRS 和前端部署在同一台电脑， 由安卓设备通过 RTMP 推流，再通过 WHEP / WebRTC 拿到低延迟画面。

等待安卓 RTMP 推流

请先启动 SRS，再让安卓设备把 RTMP 推到默认地址。

目标延迟：约 300ms 到 1200ms，取决于安卓设备、局域网质量和本机网络栈状态。

状态说明

  • 连接中：页面已向 SRS 发起 WHEP/WebRTC 建连。
  • 播放中：浏览器已收到直播媒体流。
  • 连接失败：通常是 SRS 没启动、安卓端没推流或防火墙拦截了 8000/udp。

默认推流信息

  • RTMP_URL=rtmp://<Windows电脑IP>:1935/live/obs1
  • WHEP_URL=http://127.0.0.1:1985/rtc/v1/whep/?app=live&stream=obs1
  • 安卓端要求：DJI H.264 / RTMP / 无音频
